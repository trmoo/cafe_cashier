# C++ Cafe — 카페 주문·계산 프로그램

명령 프롬프트에서 돌아가는 카페 포스(POS) 프로그램입니다.
손님에게 메뉴를 받아 값을 매기고, 영수증을 뽑고, 하루 매출을 파일에 기록합니다.
C++ 수업에서 **클래스·상속·연산자 오버로딩·예외 처리·파일 입출력**을 한 번에 보여 주려고 만든 코드입니다.

- 소스: [`cafe_cashier.cpp`](cafe_cashier.cpp) 파일 하나 (약 490줄)
- 필요한 것: C++ 컴파일러 (Visual Studio 권장) · 윈도우
- 외부 라이브러리 없음 — 표준 라이브러리(`iostream` `fstream` `ctime`)만 씁니다

---

## 무엇을 하는가

1. 영업을 시작할지 묻고, 오늘 날짜(YYMMDD)를 받는다.
2. 손님이 올 때마다 주문을 받는다. 차·커피·케이크를 고르고, 세부 메뉴와 옵션(Hot/Ice, 크기)을 고르면 값이 자동으로 더해진다.
3. 한 손님이 여러 잔을 시킬 수 있고, 다 시키면 합계를 알려 준다.
4. 영수증을 원하면 `영수증.txt` 파일로 뽑아 준다.
5. 영업을 끝내면 **오늘 총 수입**과 **손님 수**를 화면과 판매 기록 파일에 함께 남긴다.
6. 끝내기 전에 판매 기록 파일을 화면으로 읽어 볼 수 있다.

잘못된 값을 넣으면 `throw` 로 예외를 던져 잡은 뒤 같은 질문을 다시 합니다.

## 메뉴와 가격

| 메뉴 | 기본 가격 | Ice 선택 | Venti 선택 | 최고가 |
|---|---:|---:|---:|---:|
| Tea | 2,500원 | +500원 | +800원 | 3,800원 |
| Coffee | 2,000원 | +600원 | +500원 | 3,100원 |
| Cake | 5,000원 | — | — | 5,000원 |

Hot 과 Short 를 고르면 추가 요금이 없습니다. 케이크는 옵션이 없습니다.

| 메뉴 | 세부 메뉴 5가지 |
|---|---|
| Tea | Green / Lemon / Chai / Yuja / Mint |
| Coffee | Americano / Hazlenut Latte<sup>※</sup> / Espresso / Dolce Latte / Coffee Mocha |
| Cake | Chocolate / Cheese / Red Velvet / Sweet Potato / Carrot |

<sup>※</sup> 코드에 적힌 그대로입니다. 바른 철자는 `Hazelnut` 입니다.

## 만들어지는 파일 2개

프로그램을 실행한 폴더에 텍스트 파일 두 개가 생깁니다.

### `날짜 별 판매 기록 파일.txt` — 이어 쓰기

지울 일 없이 **매번 뒤에 덧붙습니다**(`ios::app`). 날마다 실행해도 기록이 쌓입니다.

```
-------<<260806>>-------
Tea -  Green - Ice - Venti = 3800
Coffee - Americano - Hot - Short = 2000
오늘 가게의 총 수입 = 5800
오늘 손님 수 1
```

### `영수증.txt` — 덮어쓰기

손님이 영수증을 받겠다고 할 때마다 **새로 씁니다**. 앞 손님 영수증은 지워집니다(프로그램도 이 점을 안내합니다).

```
C++ Cafe
날짜:260806
시각: Current time is 21:5:33

총 금액:5800
```

## 빌드와 실행

### Visual Studio (권장)

1. **새 프로젝트 → 빈 프로젝트(C++)** 를 만든다.
2. 솔루션 탐색기의 **[소스 파일]** 에 `cafe_cashier.cpp` 를 추가한다.
3. `Ctrl + F5` (디버깅하지 않고 시작).

빌드할 때 `error C2440` 이 뜨면 **프로젝트 속성 → C/C++ → 언어 → 준수 모드**를 **아니요(`/permissive`)** 로 바꿔 주세요. 아래 [알려진 제약](#알려진-제약과-고칠-거리) 3번 때문입니다.

### 명령줄 — MSVC

`x64 Native Tools Command Prompt for VS` 를 열고:

```bash
cl /EHsc cafe_cashier.cpp
```

오류가 나면 `cl /EHsc /permissive cafe_cashier.cpp` 로 다시 해 보세요.

### 명령줄 — MinGW g++

```bash
g++ -fpermissive -o cafe_cashier cafe_cashier.cpp
```

### 한글이 깨질 때

소스 파일은 **CP949(ANSI)** 로 저장되어 있습니다. 한글이 `?????` 로 나오면 실행 전에 명령 프롬프트의 코드 페이지를 맞춰 주세요.

```bash
chcp 949
```

파일을 UTF-8 로 바꿔 저장하면 한글 주석과 출력이 깨질 수 있으니 주의하세요.

## 코드 구조

```
Cafe                    주문 받기 · 메뉴 출력 · 영수증 발급 · 현재 시각 기록
 └── Food               가격(price) 보관 · operator+ 로 옵션 값 더하기
      ├── Tea           기본 2,500원 · 세부 메뉴 · Hot/Ice · Short/Venti
      ├── Coffee        기본 2,000원 · 세부 메뉴 · Hot/Ice · Short/Venti
      └── Cake          기본 5,000원 · 세부 메뉴만
```

| 함수 | 하는 일 |
|---|---|
| `main()` | 영업 시작·날짜 입력 → 손님 반복 → 하루 정산 → 기록 파일 열람 |
| `Cafe::Order()` | 한 손님의 주문을 끝까지 받아 합계를 돌려준다 |
| `Cafe::showMenu()` | 큰 메뉴(Tea/Coffee/Cake)를 화면에 뿌린다 |
| `Cafe::printReceipt()` | `영수증.txt` 를 만든다 |
| `Cafe::saveCurrentTime()` | `time(0)` 초를 시·분·초로 쪼개 한국 시각(+9)으로 적는다 |
| `Food::operator+()` | 옵션을 고를 때 기본 가격에 추가 요금을 더한다 |
| `set___()` 계열 | 세부 메뉴·Hot/Ice·크기를 묻고 파일에 적는다 |

### 이 코드에서 볼 수 있는 C++ 문법

- **클래스와 상속** — `Cafe` → `Food` → `Tea`/`Coffee`/`Cake` 3단 상속
- **생성자 초기화 리스트** — `Tea() : Food(2500) {}` 로 부모 생성자에 기본 가격 넘기기
- **연산자 오버로딩** — `void operator+(int)` 로 `(*this) + 500;` 처럼 쓰기
- **접근 지정자** — `price` 는 `protected`(자식이 씀), `IceHot`·`size` 는 `private`
- **예외 처리** — `try`/`catch`/`throw` 로 잘못된 입력 되묻기, `int` 와 `char` 를 따로 잡기
- **파일 입출력** — `ofstream`(이어 쓰기 `ios::app` 포함) · `ifstream` · `get()` 으로 EOF 까지 읽기
- **참조 전달** — `ofstream &fout` 을 함수마다 넘겨 같은 파일에 이어서 쓰기

## 알려진 제약과 고칠 거리

수업에서 그대로 쓰기보다 **"여기를 어떻게 고칠까"** 하고 물어보기 좋은 대목들입니다.

1. **숫자 자리에 문자를 넣으면 무한 반복** — 메뉴에서 `a` 같은 글자를 넣으면 `cin` 이 실패 상태로 굳어, 같은 질문이 끝없이 되풀이됩니다. `cin.clear()` 로 상태를 풀고 `cin.ignore()` 로 남은 입력을 버려야 합니다.
2. **`operator+` 가 값을 돌려주지 않습니다** — 반환형이 `void` 라 자기 자신을 바꿉니다. 이름은 `+` 인데 하는 일은 `+=` 입니다. "덧셈은 결과를 돌려주고 피연산자를 바꾸지 않는다"는 원칙과 비교해 보기 좋습니다.
3. **`char* file = "...";`** — 문자열 상수를 `char*` 에 대입하는 옛 문법입니다. C++11 이후 표준에서는 허용하지 않아, 준수 모드가 켜진 최신 컴파일러는 오류를 냅니다. `const char*` 로 바꾸면 됩니다.
4. **`catch (char* s)` 가 못 잡을 수 있습니다** — `throw "다시 입력하세요.";` 가 던지는 값의 형은 `const char*` 인데 받는 쪽은 `char*` 입니다. 표준을 엄격히 지키는 컴파일러에서는 잡지 못해, 날짜 확인에서 `n` 을 누른 순간 프로그램이 그대로 끝납니다. `catch (const char* s)` 로 고치면 됩니다.
5. **상속 관계가 어색합니다** — `Food` 가 `Cafe` 를 상속받아 차와 케이크가 `showMenu()`·`printReceipt()` 까지 물려받습니다. "차는 카페의 한 종류인가?"(is-a) 를 따져 보면, 카페가 음식을 **가지는**(has-a) 쪽이 자연스럽습니다.
6. **시각 계산** — `int totalSeconds = time(0);` 은 `time_t` 를 `int` 에 담아 2038년에 넘칩니다. 또 `currentHour + 9` 가 24를 넘어도 그대로 찍혀 `25:3:7` 같은 값이 나옵니다. `% 24` 를 한 번 더 하거나 `localtime()` 을 쓰면 됩니다.
7. **`case 'y':` 뒤에 `break` 가 없습니다** — 마지막 반복문에서 `case 'e'` 로 흘러 내려갑니다. 여기서는 둘 다 종료라 결과가 같지만, 일부러 그랬는지 표시가 없습니다.
8. **`system("pause")` 는 윈도우 전용**이라 다른 운영체제에서는 동작하지 않습니다.
9. **영수증은 한 장만 남습니다** — 위 [`영수증.txt`](#영수증txt--덮어쓰기) 설명 참고.
